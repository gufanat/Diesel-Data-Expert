Це спеціалізований програмний модуль для майстрів-діагностів СТО, призначений для миттєвого пошуку технічних параметрів дизельних форсунок систем Common Rail.

Проєкт розроблено під час переддипломної практики. для автоматизації роботи з технічними регламентами.

# Основні можливості
Миттєвий пошук - знаходить дані за частиною номера форсунки (навіть якщо маркування пошкоджене).

Повна технічна карта - видає зазори AH, RNH, електричний опір та моменти затяжки.

Велика база - підтримка брендів Bosch, Delphi, Denso та VDO (Siemens).

Автономність - працює без підключення до інтернету.

Портативність - не потребує встановлення Python для запуску версії

# Як запустити
Варіант 1: Для користувачів
1. Перейдіть у розділ Releases.
2. Завантажте архів Diesel-Data-Expert-v1.0.zip
3. Розпакуйте та запустіть файл main.exe
  (Python встановлювати не потрібно.)

Варіант 2: Для розробників:
1. Клонуйте репозиторій (git clone https://github.com/ВашеІмя/diesel-data-expert.git)
2. Перейдіть у папку проєкту (cd diesel-data-expert)
3. Запустіть програму python main.py

# Технологічний стек
Мова - Python 3.14.4
Архітектура - Об’єктно-орієнтоване програмування (OOP)
База даних - In-memory dictionary (для максимальної швидкодії)
Збірка - PyInstaller (створення автономного виконуваного файлу)

# Приклад роботи
Користувач вводить частину номера (наприклад, 183), і програма видає:

ІНФОРМАЦІЯ ПРО ФОРСУНКУ: 0445110183

Бренд:          Bosch

Тип:            CRI 2.1

Зазор AH:       0.055 мм

Зазор RNH:      0.052 мм

Опір котушки:   15.8 Ом

Момент затяжки: 55Нм + 90°

Застосування:   Opel/Fiat 1.3 CDTI
