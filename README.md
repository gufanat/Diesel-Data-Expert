# Diesel-Data-Expert
Це спеціалізований програмний модуль для майстрів-діагностів СТО, призначений для миттєвого пошуку технічних параметрів дизельних форсунок систем Common Rail. Проєкт розроблено під час переддипломної практики на базі ФОП Чорнобривець В.М. для автоматизації роботи з технічними регламентами.

Керівник роботи — Олена Бабич.

# Завдання до переддипломної практики
Розробити програмний продукт для автоматизації ідентифікації тест-планів паливної апаратури. Програма повинна забезпечувати швидкий пошук зазорів анкера (AH) та ходу голки (RNH), електричного опору та моментів затяжки за фрагментом номера форсунки. Вихідні дані включають параметри систем Bosch, Delphi, Denso та VDO.

# Основні можливості
1. Миттєвий пошук - знаходить дані за частиною номера форсунки (навіть якщо маркування пошкоджене).
2. Повна технічна карта - видає зазори AH, RNH, електричний опір та моменти затяжки.  
3. Велика база - підтримка брендів Bosch, Delphi, Denso та VDO (Siemens).  
4. Автономність - працює без підключення до мережі інтернет.  
5. Портативність - не потребує встановлення Python для запуску виконуваної версії.

# Використані технології
1. Мова розробки - Python 3.14.4
2. Архітектура - Об’єктно-орієнтоване програмування (OOP)
3. Керування версіями - Git / GitHub
4. База даних - In-memory dictionary (для максимальної швидкодії)
5. Збірка - PyInstaller (створення автономного .exe файлу)

# Опублікований продукт
Інсталяційний пакет (версію для Windows) можна завантажити у розділі Releases цього репозиторію.

# Як запустити:
1. Для користувачів - Завантажте архів з релізів, розпакуйте та запустіть файл main.exe.
2. Для розробників -
   git clone https://github.com/Oleksandr-Tril/diesel-data-expert.git
   cd diesel-data-expert
   python main.py

# Приклад роботи
Користувач вводить частину номера (наприклад, 183), і програма видає:

ІНФОРМАЦІЯ ПРО ФОРСУНКУ: 0445110183

Бренд: Bosch

Зазор AH: 0.055 мм

Момент затяжки: 55Нм + 90°

Застосування: Opel/Fiat 1.3 CDTI
